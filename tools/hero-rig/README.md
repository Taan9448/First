# hero-rig — 게임용 영웅 도트 리그 (19단계 시안, 개발 전용)

시안 그림을 따지 않고 처음부터 새로 그린 영웅 도트를 만드는 도구다. 아직 게임(`index.html`)에는 들어가지 않는다.

- `rig.js` 렌더러: 다각형·캡슐·타원·손도트 부위를 뒤에서 앞으로 칠한다. 빛·그늘 띠, 부위 경계선, 바깥 외곽선은 자동으로 넣는다. 브라우저(`Game.Rig`)와 node에서 모두 돈다
- `harin.js` 하린: 얼굴(눈·입)만 칸으로 찍고, 머리채·소매·하카마·허리띠·묵검은 자세 값(팔 각도·검 각도·바람·몸 기울기)으로 움직인다. 동작 표 `ANIM`에 대기 6 · 공격 8 · 스킬 16장면이 있다
- `node preview.js 3` → `sheet.png`(동작별 장면 전체), `node gen.js` → `harin_data.json`(글자 격자 + 팔레트)

한 장면은 96×72 도트이고 몸은 약 36×48이다. 하린이 확정되면 같은 렌더러로 나머지 네 영웅을 만들고 전투에 넣는다.
