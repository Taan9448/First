# 다섯 영웅의 원정 — 새 세션용 작업 요약 (인수인계서)

이 문서를 새 Claude Code 세션의 첫 메시지로 붙여넣고 "이 요약대로 처음부터 만들어 줘. 먼저 GAME_DESIGN.md부터 작성해서 저장소에 커밋해 줘"라고 요청한다.
아래 내용은 이전 세션에서 7단계까지 만들면서 확정한 결정 사항이다. 세부 수치(카드 192장 목록, 몬스터 수치)는 이전 GAME_DESIGN.md에 있었고, 여기에는 규칙과 방향만 적는다.

- 글자를 새로 넣으면 `python3 tools/embed-fonts.py`(빠지면 `test-battle`이 알려 준다). 테스트: `node tools/test-battle.js`, `node tools/test-campaign.js`, 밸런스: `node tools/sim.js 12 1 0 normal|hard`

## 1. 기본 조건
- 브라우저용 턴제 덱빌딩 전략 카드 게임(Slay the Spire 계열), 파티 3인 편성

- 진행 상황은 localStorage 자동 저장(버전 번호 + 마이그레이션). 설정은 별도 키

## 3. 게임 구조
- 10 스테이지 = 5 테마 × 2: 속삭이는 숲(중독) → 타오르는 사막(방해 카드 '모래' + 약화) → 얼어붙은 설원(한기 3중첩 → 빙결) → 용암 화산(화상 누적, 죽을 때 폭발) → 마왕성(취약 + 힘 누적 + 흡혈)
- 홀수 스테이지는 정예로, 짝수는 보스로 끝남. 10 스테이지: 전투 → 중간 보스(기사단장 발타르) → 휴식/상점 → 최종 보스(마왕 아스타로트, 3페이즈)
- 노드: 전투 2~3회 → 휴식/상점 선택 → 정예/보스. 체력은 스테이지 안에서 유지, 스테이지 시작 시 완전 회복. 쓰러진 캐릭터는 전투 후 25%로 복귀
- 패배 시 스테이지 처음부터(카드·골드 유지). 클리어한 스테이지 재도전 가능
- 몬스터 36종(테마당 일반 5 + 정예 1 + 보스 1, 최종 보스 1). 몬스터는 다음 행동을 머리 위에 예고(수치·대상 포함)
- 보스 패턴: 소환(최대 4마리), 체력 조건 발동(격노·페이즈 전환·패턴 교체·매 턴 효과), 차지(보호막을 깨면 취소), 1회 부활(불사조), 종말 카운트다운(최종 보스)

## 5. 전투 규칙
- 매 턴 에너지 3, 5장 드로우, 턴 종료 시 손패 버림, 손패 상한 10. 덱이 비면 버린 더미를 섞음
- 피해 = (기본 + 힘) × 약화 0.75 × 취약 1.5 × 치명타(2배 + 치명 강화 0.5/중첩), 내림. 보호막 먼저 차감
- 약화·취약은 라운드(내 턴 + 적 턴) 끝에 1 감소, 적 턴에 걸린 것은 그 라운드에 줄지 않음
- 중독(턴 종료 피해, 보호막 무시, 1 감소), 화상(턴 종료 피해, 보호막에 막힘, 절반으로), 재생, 가시, 도발, 집중(확정 치명), 예리함(치명 +10%/중첩), 한기→빙결(보스는 이후 2턴 면역), 정지
- 지속 카드: 즉시 효과 + 반복 효과(턴 시작/턴 종료/공격 카드 사용 시)
- 조건부 카드: 효과에 if(조건, 충족, 아님). 조건 예: 이번 턴 첫 카드, 이번 턴 공격 카드 수, 직전 카드 유형, 남은 손패·에너지, 적 수, 아군 생존, 자신·대상 체력/보호막/상태, 대상의 공격 예고. 손패에서 지금 쓰면 충족되는 카드에 "조건 충족" 표시
- 무작위 카드: 수치 범위, 동전 던지기, 여러 효과 중 하나, 무작위 디버프, 무작위 카드 생성(그 턴만, 비용 0), 손패 비용 섞기. 결과를 화면에 글자로 표시
- 카드 사용: 클릭 → 대상 클릭, 또는 대상 위로 드래그(조준 화살표). 우클릭/ESC 취소

## 6. 카드 (192종)
- 소유자별 32장 × 6(캐릭터 5 + 공용). 등급 분포: 일반 67 / 고급 47 / 희귀 34 / 영웅 30 / 전설 14
- 캐릭터별 기본 카드 8장, 공용 기본 15장. 시작 시 카이 8 + 공용 15. 합류하면 그 캐릭터 기본 카드 지급
- 전체의 약 1/3이 조건부, 약 26장이 무작위 요소, 치명타 관련 카드 다수
- 종류당 1장 보유. 덱 = 편성 캐릭터별 덱(6~10장) + 공용 덱(6~10장). 얻은 카드는 자리가 있으면 자동으로 덱에 들어감. 덱 편집 화면과 자동 구성 버튼
- 보상: 일반 전투 골드 15~25 + 카드 3장 중 1장(건너뛰면 +10골드), 정예는 고급 이상, 보스는 희귀 이상. 스테이지가 오를수록 높은 등급 확률 증가
- 상점: 카드 5장(가격 30/55/90/150/250), 치료 40골드(전원 25%), 새로고침 20골드. 휴식: 전원 35% 회복
- 희귀 이상 카드는 사용 순간 고유 이펙트(sfx) 보유

## 7. 아트·UI 방향 (중요)
- 캐릭터·몬스터: **도트(픽셀 아트)**. 글자 격자로 왼쪽 절반만 적고 좌우 대칭으로 펼친 뒤 비대칭 부분 덧그림. 그릴 때 윤곽선 1px과 음영(윗변 밝게, 아랫변·오른쪽 어둡게)을 자동 적용. 색만 바꾼 변형 지원. 화면의 도트 1칸 크기는 CSS 변수 하나로 통일, 숨쉬기 2프레임
- 캐릭터마다 공격 자세 프레임: 카이는 칼을 앞으로 휘두름, 브리아는 방패를 내밂, 녹스는 단검을 찌름, 리라·세라는 지팡이 끝이 빛남. 무기 끝 좌표에서 이펙트·마법 탄 발사
- 카드: 속성별 배경 + 카드별 일러스트(SVG 글리프) + 등급별 금속 프레임(모서리 장식, 이름 띠, 유형 메달, 등급 보석)을 그린 뒤 **낮은 해상도 캔버스로 찍어 도트 그림으로 변환**. 영웅·전설은 광택 띠가 흐름. 카드 크기는 CSS 변수(--ch) 하나, 내부는 em 단위
- 전투 배경 5종도 SVG로 그린 뒤 도트로 변환 + 떠다니는 픽셀 입자
- UI 전체 도트풍: 둥근 모서리·부드러운 그라데이션·흐림 금지. 계단 모서리 테두리(box-shadow), 번짐 없는 그림자, 움직임은 steps(). 네이비 + 시안 + 골드
- 이펙트: 저해상도 캔버스에 픽셀 단위로 그림(원·선·궤적 모두). 카드가 손에서 대상으로 날아가 부서짐, 공격 시 돌진, 마법 탄 포물선, 피격 번쩍임·밀려남·짧은 멈춤, 치명타 화면 펀치, 쓰러지면 조각나 흩어짐, 승리 축포. 이펙트 강도 '낮음' 옵션

## 8. 화면과 기능
- 타이틀(이어하기/새 게임) → 스테이지 맵(10개 노드 + 진행 트랙) → 파티 편성 → 전투 → 보상 → 휴식/상점 → 스테이지 클리어(합류 연출)
- 오른쪽 위 공통 메뉴: 도감(카드 필터·수집률·미획득 실루엣 / 몬스터 만난 것만·처치 수 / 캐릭터), 덱 편집(전투 중 잠금), 설정(볼륨·이펙트 강도·1x/2x·튜토리얼 다시 보기·저장 초기화)
- 첫 전투 튜토리얼 7단계(대상 강조 + 말풍선)
- `?debug=1`: 전체 해금, 별도 저장 키, 적 즉사 버튼, 골드 +500, 전원 회복, 도감에서 카드 클릭 시 손패 추가

## 9. 밸런스 메모
- 간단한 AI로 캠페인 전체를 반복 플레이하는 시뮬레이터를 만들어 스테이지별 실패율을 확인한다(개발 전용 파일, 게임에 포함하지 않음)
- 목표: AI 기준 초반은 거의 첫 시도에 클리어, 후반 보스는 1~3번 시도. 이전 세션에서 후반 보스(화룡, 발타르, 마왕)와 파라오가 어려워 체력·공격력을 10~20% 하향함

## 10. 이전 세션에서 겪은 주의점
- file:// 에서도 동작해야 하므로 모듈·fetch를 쓰지 않는다. SVG→캔버스 변환은 data URL 이미지로 하면 file://에서도 된다
- 손패를 매번 다시 그리면 무거우므로 상태가 같으면 건너뛴다
- 전투 로직은 이벤트(fx:damage 등)만 내보내고, 그리기는 UI가 맡는다. 테스트 시 Game.wait를 즉시 완료로 바꾸면 빠른 자동 플레이가 가능하다
