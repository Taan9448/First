# 천외검결 — SD 일러스트와 UI 스타일 가이드

2026-10-04 · ChatGPT Art Director / UI·UX · UI 방향 검토용 초안

사용자의 최신 요청에 따라 도트 SD에서 **SD 그림풍**으로 바뀐 캐릭터에 맞춰 UI를 먼저 제안한다. 승인된 `assets/characters/{kai,bram,lyra,sera,nox,ciel}_poses.png`의 외형·색·비례·빛을 기준으로 삼고 기존 그림은 유지한다. 화면 시안은 새 UI의 제안이며 사용자 승인 전이다.

## 화풍과 재질

또렷한 외곽선, 풍부하지만 정돈된 채색, 약 2.3~2.7등신의 SD 일러스트를 사용한다. UI는 매끄러운 윤곽과 얇은 테두리로 캐릭터를 받쳐 준다. 도트 계단 테두리, 스캔라인, 픽셀 글꼴을 새 UI의 기본 장식으로 사용하지 않는다.

공통 표면은 짙은 먹색 옻칠, 설명 영역은 따뜻한 한지, 테두리는 절제한 금박이다. 무림은 먹의 흐름·붉은 매듭·산수, 엘단은 보석·금속·기하학 마법진, 세계의 틈은 청록과 보라의 균열을 쓴다. 같은 패널에 모든 장식을 겹치지 않는다. 장식은 주로 모서리와 제목 주변에 둔다.

## 팔레트

아래 값은 UI 제안 토큰이며 기존 캐릭터의 색을 다시 칠하기 위한 값이 아니다.

| 용도 | 색 | 적용 |
|---|---|---|
| 먹색 | `#111820` | 패널·상단바·카드 받침 |
| 남빛 | `#202D40` | 보조 면·서양 판타지 그림자 |
| 한지 | `#F0E4CB` | 카드 설명·정보 창 |
| 금박 | `#C5A261` | 1~2px 테두리·선택 강조 |
| 옻칠 적색 | `#9F2934` | 원정·턴 종료·공격 계열 |
| 청록 | `#54C7C0` | 에너지·현재 지점·마법 활성 |
| 보라 | `#8D70BD` | 세계의 틈·특수 계열 |
| 생명 녹색 | `#80BA79` | 체력 |
| 결계 청색 | `#6FB8E4` | 보호막·방어 |

먹색 위 본문은 한지색, 한지 위 본문은 먹색을 쓴다. 금색은 긴 본문에 쓰지 않는다. 텍스트 대비는 일반 본문 4.5:1 이상, 큰 글자와 기능 경계 3:1 이상을 목표로 실제 구현에서 검사한다. 상태는 색과 함께 아이콘·이름·수치로 구별한다.

## 선·빛·비례

- 캐릭터는 승인된 원본의 SD 머리 크기와 실루엣을 유지한다. UI 시안 안에서 재해석된 캐릭터를 새 원본으로 추출하거나 교체하지 않는다.
- 512px 캐릭터의 외곽선은 약 2~4px, 내부선은 약 1~2px를 목표로 한다. 크기보다 축소 후 얼굴·무기·옷 구분이 기준이다.
- 빛은 왼쪽 위, 명암은 주요 2~3단계와 선택적인 금속·보석 하이라이트로 정돈한다. 광채가 얼굴과 정보 창을 덮지 않는다.
- 1280×800 기준 UI 경계선은 1~2px, 패널 모서리는 4~8px 또는 작은 사선 마감으로 통일한다. 모든 패널에 두꺼운 금테를 두르지 않는다.
- 기본 간격은 8px 배수, 화면 가장자리 안전 여백은 24px. 누르는 영역은 최소 44×44px를 권장한다.

## 글자와 정보

이미지 안에 글자·숫자·서명·워터마크를 넣지 않는다. 이름·비용·효과·수치·단축키는 Claude가 HTML/CSS로 표시한다. 한글 본문은 읽기 쉬운 고딕 15~16px, 카드 설명은 최소 14px, 제목은 명조 24~32px를 제안한다. 붓글씨는 큰 화면 제목에만 제한적으로 쓴다. 최종 글꼴은 라이선스와 오프라인 포함 여부를 확인해 Claude가 선택한다.

정보 우선순위는 적 행동 예고·체력·카드 효과·에너지·주요 조작, 그다음 상태·유물·부가 정보, 마지막 장식이다. 긴 효과는 확대 카드/툴팁으로 전체 문장을 제공한다. 중요한 효과를 생략하거나 장식으로 대체하지 않는다.

## 카드·아이콘·상태

카드 그림과 설명 영역을 분리한다. 비용은 좌상단, 소유 동료는 작은 초상과 이름, 등급은 테두리와 별도 표식으로 구별한다. 무공은 한지·수묵·적색, 마법은 남빛·청록·기하학, 합동기는 양쪽 특징이 만나는 틀을 제안한다. 효과 그림이 설명 영역을 침범하지 않는다.

128px 아이콘은 22~32px에서 검사한다. 검·방패·독방울처럼 한 실루엣에 한 의미를 담고 굵은 외곽선을 쓴다. 파일 자체에 배경 원판을 그리지 않는다. UI가 놓는 소켓이나 버튼 표면과 아이콘 그림은 별개다. 상태 수치는 이미지에 넣지 않는다.

기본은 얇은 금테, 호버/키보드 포커스는 분명한 밝은 윤곽, 선택은 체크·윤곽·이름 표기를 함께, 비활성은 채도를 낮추고 이유를 제공한다. 경고 적색과 긍정 청록을 색만으로 전달하지 않는다. 동작 감소 설정에서는 빛의 맥동·흔들림을 끈다.

## 파일과 금지 사항

- 캐릭터·몬스터·아이콘·카드 틀·UI 부품은 실제 알파 투명 PNG. 체크무늬나 단색을 배경으로 그린 가짜 투명은 금지한다.
- 전체 화면 목업은 **배경과 UI가 합쳐진 불투명 PNG**이며 게임에 꽂는 개별 부품이 아니다. 승인 후 필요한 부품을 요청 규격에 맞춰 따로 제작한다.
- 기존 승인 그림의 재생성·덮어쓰기, 외형·무기·성별 변경, 무협과 무관한 SF HUD, 과도한 금빛·네온·입자, 작은 글자의 금박 처리, 낮은 대비, 마법진의 읽을 수 있는 문자 표현을 금지한다.
- 완성 리소스는 `docs/ASSET_SPEC.md`의 경로·이름·비율·투명 조건을 따른다. UI 부품 크기는 승인 후 Claude가 요청서에 확정한다.

화면별 배치와 기존 기능 유지 목록은 [UI_REDESIGN_PROPOSAL.md](UI_REDESIGN_PROPOSAL.md)에 있다.
