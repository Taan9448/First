2026-10-04 · 실제 PNG 파일을 디코딩한 검사 기록

권장 크기와 실제 제작 크기는 다를 수 있다. 기존 규격은 비율 오차 ±3%, 권장 크기의 절반 이상을 허용한다. 아래는 실제 파일 크기이며 이미지 원본을 리사이즈·재채색한 결과가 아니다. 전체 화면 목업은 불투명, 캐릭터·몬스터·아이콘·UI 부품은 실제 알파 PNG다. 기존 적용 파일과 이번 새 전달을 구분한다. 새 전달은 방향에 맞춘 디자인이며 개별 결과의 사용자 검토와 Claude 연결이 남아 있다.

게임 코드와 리소스 등록 목록은 이 전달에서 변경하지 않았다. 공유 삽화는 새 연결 규칙이 필요하다.

## 알파 확인

RGBA 파일은 알파 최솟값 0 및 0보다 큰 픽셀이 함께 있어 실제 투명/실체가 존재함을 확인했다. 알파 최댓값이 254인 동료 전신도 완전히 투명한 외부와 불투명에 가까운 인물 영역을 갖는다. 일부 미리보기에서 나타나는 숨겨진 RGB 색은 투명 픽셀의 알파값과 별개다. 체크무늬를 배경으로 그린 파일이 아니다.

`panel_border.png`의 캔버스 중앙 픽셀 알파는 0이다. 주요·보조 버튼의 가운데는 채워진 표면이고 바깥은 투명이다. 글자·숫자는 별도 HTML로 표시한다. 버튼 파일의 실제 캔버스 비율은 3:1, 패널 테두리는 4:3이다. 버튼의 상하 투명 여백을 고려해 별도 클릭 영역 44px 이상을 확보한다.

## 용도 구분

동료 전신은 로비·편성·이야기용이며 전투 동작의 공통 발 위치를 대신하는 그림이 아니다. 전투의 승인된 4자세 아틀라스는 그대로 유지한다. 새 전체 화면 시안 안에 있는 도감 항목·상품·노드와 카드 등은 배치 예시이며 실제 콘텐츠로 추출하지 않는다.

공유 카드 7장은 각 카드의 효과를 정확히 묘사하는 전체 개별 삽화가 아니다. K01·K25는 전용 삽화다. 신규 아이콘 원본은 1254px 정사각이고 게임에서 22~32px로 표시할 때 의미 구별을 확인한다.

## 검사 결과

- 모든 파일 디코딩과 크기/알파를 확인했다. 배경·카드·전신·목업의 비율은 규격 허용 범위 안이다. UI 부품은 이번 디자인에서 실제 크기와 비율을 정의했다.
- `node tools/sync-assets.js --check`: 크기·투명 조건 오류 없음. 새 그림의 등록 목록 불일치 1개로 종료 코드 1이다. 등록 목록은 Claude가 새 그림 연결 시 갱신한다.
- 공유 카드 7장은 현재 파서의 이름 규칙 대상이 아니므로 미등록 주의가 나온다. 크기가 권장값과 다른 원본은 주의로 표시되며 규격 오류가 아니다.
- 글자/서명 유무와 화풍은 시각 검수했다. 실제 한글/수치·해상도·대비·상호작용·file:// 연결은 Claude 적용 검증 대상이다.

카탈로그 합계: 49개 PNG · 기존 유지 15개 · 새 전달 34개.

## 독두꺼비 왕 동작 기준

알파 128 초과 실체 영역의 공통 세로 범위는 대기·공격 모두 y=156~1216(1254px 캔버스)이다. 실체 높이 84.5%, 발 기준 97.0%, 아래 여백 3.0%로 목표 범위 안이며 공격은 몸/발을 고정하고 입과 혀를 바꿨다. 두 그림 모두 왼쪽을 본다. 이 범위는 실체 기준이며 반투명 가장자리 픽셀의 최외곽과 다를 수 있다.
