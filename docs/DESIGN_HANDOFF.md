# SD 일러스트 · UI/UX 디자인 전달

2026-10-04 · ChatGPT 제작 / Claude 연결 · 디자인 전용 전달

사용자가 승인한 로비·전투·편성·월드맵 목업을 기준으로 나머지 화면, 배경, 전신 일러스트와 첫 부품을 제작했다. **이 전달에는 게임 HTML/CSS/JS·데이터 목록 변경이 없다.** 새 이미지의 연결, 저장 호환성, 실제 문구와 수치, 접근성 및 오프라인 검증은 Claude가 진행한다. 기존 6명 동작 아틀라스와 원격의 기존 배경·일반 독두꺼비는 변경하지 않았다. 원격 `cdaa9c2`의 UI·게임 변경을 기준으로 추가 디자인만 전달한다.

파일별 실제 크기·모드·알파 및 검토 상태는 [DESIGN_ASSET_CATALOG.md](DESIGN_ASSET_CATALOG.md), 색·화풍은 [STYLE_GUIDE.md](STYLE_GUIDE.md), 초기 4장의 상세 정보 구조는 [UI_REDESIGN_PROPOSAL.md](UI_REDESIGN_PROPOSAL.md)를 따른다.

## 전달 범위

- 전체 화면 시안: 요청서의 12개 주요 화면과 별도 편성 화면. 무문자 불투명 PNG이며 배치 참고 자료다. 배경이나 부품으로 추출하지 않는다.
- 배경: 타이틀을 새로 추가한다. 전투 7테마·로비·월드맵은 이미 원격에 적용된 그림을 유지하며 같은 카탈로그에서 확인할 수 있다. PNG도 허용되는 기존 규격을 따른다.
- 동료: 6명 전신 투명 일러스트. 전투 동작 파일을 대체하지 않는다. 하린은 최신 승인 외형의 **서예 붓**을 쓴다.
- 카드: K01·K25 전용 그림과 동료별 6장 + 공용 1장의 공유 그림. 공유 그림은 카드 소유자별 임시 대체 그림이며 카드 전체의 개별 삽화 제작 완료를 뜻하지 않는다.
- 몬스터: 천년 독두꺼비 왕의 대기·공격 시범. 일반 독두꺼비(`slime`) 두 동작은 원격에서 적용한 그림을 그대로 유지한다.
- 부품: 힘·중독·공격·방어 아이콘, 주요/보조 버튼, 패널 테두리. 상태 수치와 글자는 이미지에 없다.

## 공통 화면 규칙

1280×800을 기준으로 상단 64px, 외곽 여백 24px, 내부 간격 8/16/24px를 쓴다. 화면 시안의 실제 이미지가 더 큰 경우 아래 비율과 영역으로 배치하며 이미지 픽셀을 그대로 CSS 좌표로 복사하지 않는다. 길어지는 한글을 먼저 배치한 다음 장식과 일러스트를 맞춘다.

제목은 명조 24~32px, 본문은 고딕 15~16px, 카드 본문은 최소 14px를 권장한다. Noto Serif KR / Noto Sans KR 같은 한글 글꼴은 라이선스를 확인하고 로컬에 포함한다. 외부 폰트 요청에 의존하지 않는다. 기존 세로쓰기 카드 스타일은 새 가로 제목에 상속되지 않도록 확인한다.

먹색 면에는 한지색 글자, 한지 면에는 먹색 글자를 쓴다. 제목·수치는 금색만으로 읽게 하지 않는다. 일반 본문 대비 4.5:1, 큰 글자·기능 경계 3:1을 실제 화면에서 측정한다. 선택/잠김/완료는 색 외에 체크·자물쇠·문구로 구별한다. 누르는 영역 최소 44×44px, 키보드 포커스는 밝은 외곽선을 쓴다.

시안의 상품·아이콘·분기 수는 배치 예시다. 기존 데이터의 선택지 수와 문구를 우선한다. 새 통계·새 규칙·존재하지 않는 설정을 시안만 보고 추가하지 않는다. 스토리·엔딩·승천·거울 모드는 같은 제목/패널/버튼 체계를 사용하고 기존 조건부 기능을 유지한다.

## 카드와 부품 연결

카드 제목은 가로쓰기 1~2줄, 비용은 좌상단, 소유자·강화·등급은 그림과 별도 표식, 효과는 독립 한지 영역에 둔다. 긴 효과는 확대 카드에서 전체를 보여 준다. 개별 `cards/art/{id}.png`가 있으면 우선하고, 없으면 선택적으로 `cards/shared/{owner}.png`, 마지막으로 기존 코드 그림을 사용한다. 공용 카드는 `common.png`를 제안한다. 공유 폴더는 새 디자인 제안이므로 Claude가 명시적으로 분류/연결해야 한다.

버튼 PNG는 완성 표면으로 직접 표시하고 글자를 별도 요소로 가운데 놓는다. 긴 문구는 버튼을 비정상적으로 늘리기보다 문구/레이아웃을 조정한다. 패널 테두리 PNG는 가운데가 투명하며, 먹색/한지 표면을 별도 요소로 아래에 놓는다. PNG를 런타임 캔버스로 자르거나 알파를 다시 만들지 않는다. 호버·포커스·선택·비활성·오류 상태는 Claude가 외곽선과 문구로 구현한다. 이번 부품이 모든 상태용 파일을 포함하지는 않는다.

## 좁은 화면과 많은 정보

1024px에서는 두 열 구조를 유지하되 장식 여백을 줄인다. 860px 이하에서는 편성·상점·도감의 상세 패널을 선택 후 별도 보기로 열고 목록을 스크롤한다. 390px에서는 중요한 문구를 읽을 수 있게 한 열로 배치하고 손패/지도는 가로 스크롤한다. 전체 화면을 단순 축소해 글자까지 작게 만들지 않는다.

적 4마리, 상태 다수, 카드 10장 이상, 긴 한국어 이름, 보스 배너와 동료 대사가 함께 나오는 경우를 별도로 확인한다. 대사와 목표 배너는 각자 독립 공간을 사용한다. 카드 확대는 화면 밖으로 나가지 않아야 하고 대상 조준선은 실제 동료/적과 연결한다.

## Claude가 연결 전에 확인할 사항

1. 새 그림의 검토 상태와 아래 카탈로그의 알파/크기/발 기준을 확인한다. 미승인 시범은 사용자가 확인한 후 연결한다.
2. `ui/mockups`는 불투명 전체 화면 참고 자료다. 최신 도구가 이미 이 폴더를 런타임 스캔에서 제외하므로 이 동작을 유지한다. 투명 UI 규칙 자체를 완화하지 않는다.
3. `cards/shared`를 임시 공유 삽화로 분류하고, PNG 배경 경로 및 전신 일러스트 연결을 등록한다. 기존 그림과 로더의 대체 경로를 유지한다.
4. 분류 후 `sync-assets`와 요청서 생성 도구를 실행한다. 이번 디자인 전달은 생성된 `data/assets.js`·`docs/IMAGE_REQUESTS.md`를 수정하지 않았다.
5. file:// 직접 실행, 이미지 실패 시 대체 그림, 한글 글꼴 포함, 모든 메뉴·단축키·저장 호환성·레이아웃·대비를 확인한다. 디자인 파일 검수는 게임 적용 검증을 대신하지 않는다.

## 아직 제작되지 않은 묶음

동료 쓰러짐/컷인 전용 그림, 나머지 몬스터와 동작, 전체 카드 개별 삽화, 등급별 카드 프레임, 전체 상태/메뉴 아이콘, 유물/소모품, 이야기/이벤트 삽화, 던전 지도 전용 배경, 전투 이펙트는 후속 요청서 묶음이다. 기존 승인 아틀라스와 코드 그림을 유지하며 이번 파일로 전체 리소스 작업이 끝났다고 표시하지 않는다.
