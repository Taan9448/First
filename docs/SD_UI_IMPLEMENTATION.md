# 승인 목업 기준 SD UI 적용

2026-10-04 · 브랜치 `codex/sd-ui-resume`

사용자가 승인한 로비·편성·전투·월드맵 목업을 기준으로 게임의 표시 코드를 변경했다. 이전 세션의 마지막 작업은 커밋·푸시되지 않아 이 환경에 없었으며, GitHub의 `codex/sd-ui-mockups`에서 목업과 가이드를 복구해 구현했다. 목업 PNG는 검토 자료이고 게임 배경으로 사용하지 않는다.

## 구현

- `css/sd-theme.css`: 먹색 옻칠 패널, 한지 설명, 얇은 금테, 청록 선택, 붉은 주요 버튼. 공통 버튼·모달·도감·설정·대장간·보상·상점·휴식·이야기도 같은 토큰을 사용한다. 기존 CSS 위에 적용하며 게임 화면과 메뉴를 유지한다.
- 로비: 동료를 크게 표시하고 오른쪽 원정·지도·편성·덱·동료·스토리·대장간을 재배치했다. 대사와 목표 배너를 분리했다. 타이틀과 로비는 새 준비실 배경을 공유한다.
- 편성: 6명 3×2 선택 영역과 최대 3명의 출전 요약. 역할·직업·레벨·체력·치명타·덱·합류 조건·준비/스테이지 덱 구분을 유지한다. Enter/Space 선택과 포커스를 지원한다.
- 카드: 모든 계열의 이름을 가로로 표시하고 효과를 한지 면에 배치한다. 효과 글꼴은 14px 이상이다. 무공에도 소유자·종류·계열 정보를 표시한다. 전용 그림이 없으면 승인된 동료 아틀라스와 기존 효과 글리프를 함께 사용한다. 긴 문장의 전체 내용은 기존 툴팁에 유지한다.
- 캐릭터: 승인된 6명의 원본·4자세 좌표는 그대로 사용한다. 로비·편성·전투·카드의 표시 크기와 주변 UI를 맞췄다. 별도 새 전신 일러스트나 연속 애니메이션 프레임을 만들었다고 주장하지 않는다.
- 배경: 로비, 월드맵, 숲·사막·설원·문파·화산·틈·거울의 7개 전투 테마. 월드맵은 실제 지점 배치에 맞춰 사막·설원·화산 지형을 배치한다. 노드·진행·해금·재도전은 기존 데이터로 표시한다.
- 몬스터: 독두꺼비(`slime`) 대기·공격 투명 PNG를 연결했다. 나머지는 기존 그림과 동작을 유지한다.
- 공통 SVG: 카드 프레임·효과 그림·대체 배경을 저해상도 캔버스로 변환하지 않고 SVG data URL로 표시한다. 기존 `raster`와 코드 스프라이트는 유지한다. 주요 메뉴 아이콘은 부드러운 SVG를 제공하고 나머지는 기존 아이콘으로 대체한다.
- 글꼴: Noto Sans CJK KR의 사용 문자 서브셋을 WOFF로 내장했다. 라이선스는 `css/NotoSansCJK-LICENSE.txt`. 재생성: `python tools/embed-sd-fonts.py [로컬 글꼴 경로] [컬렉션 번호]`. 런타임에 외부 접속이나 추가 패키지가 필요하지 않다.
- `tools/sync-assets.js`: `assets/ui/mockups/`만 런타임 목록에서 제외한다. 실제 투명 UI 부품의 검사는 유지한다.

## 검증

- `node tools/test-battle.js 6000`: 전투 오류 0, 전체 검사 통과.
- `node tools/test-campaign.js`: 전체 검사 통과.
- `node tools/sync-assets.js --check`: 규격 오류 0. 생성 배경은 1672×941이며 비율 허용 범위 안이라 원본 그대로 사용한다. 권장 해상도 차이는 주의로 표시된다.
- `tools/check-sd-ui.js`: Chromium에서 외부 HTTP 접속을 차단하고 로컬 서버로 검사. 로비·편성·맵·대장간·도감·보상·상점·휴식·전투, 동료 6명, 키보드 선택, 적 4마리, 기록 열기/닫기, 턴 종료, 카드 가로쓰기/14px 글꼴, 내장 글꼴, 대사/배너 비겹침을 확인했다. 1280×800, 1000×680, 1440×900. 실행 오류 0.
- JavaScript 문법과 `git diff --check` 통과.

브라우저 정책이 `file://` 탐색을 차단해 직접 파일 실행은 미검증이다. 상대 경로·일반 스크립트·Image·CSS 배경을 유지하고 모듈·fetch·PNG 캔버스 가공은 추가하지 않았다. 기존 최소 화면 폭 860px은 유지한다. 전체 카드 개별 삽화·전체 몬스터 새 그림·전용 쓰러짐 PNG·모바일 전용 재배치는 이번 구현에 포함되지 않는다.

## 중단 오류와 재개 방식

`decoded message length too large`는 디코딩된 메시지 99,616,483바이트가 67,108,864바이트(64MiB) 제한을 넘었다는 뜻이다. 이 메시지만으로 어떤 이미지나 요청이 원인인지 확정할 수 없다. 앱 내부의 제한을 수정한 것은 아니며, 이번 작업은 세션 기록을 요약해서 읽고 원본 이미지·내장 글꼴을 통째로 출력하지 않으며 파일 경로로 처리했다. 작업 결과는 Git에 저장해 재개할 수 있도록 했다.
