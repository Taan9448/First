# Claude 적용용 UI 키트

2026-10-04 · 승인 목업을 실제 DOM/CSS 부품으로 옮긴 디자인 구현 자료

`index.html`을 직접 열면 버튼·카드·패널·체력바·예고·편성·설정 등 개별 부품과 로비/전투/편성/시스템 조합을 볼 수 있다. HTML의 한글·수치는 이미지 위에 별도 요소로 표시된다. **게임 본체에 자동 연결되는 패치는 아니다.** `ui-kit.css`는 실제 적용 가능한 부품 스타일이고, `preview.js`는 샘플 데이터를 보여 주는 미리보기 조작만 담당한다. Claude가 기존 렌더러와 이벤트에 부품을 연결한다.

## 파일

| 파일 | 용도 | 게임 연결 |
|---|---|---|
| `ui-kit.css` | 색·여백·상태·레이아웃·실제 부품 CSS | Claude가 경로/셀렉터를 맞춰 이식 |
| `game-skin.css` | 현재 게임 클래스에 맞춘 선택형 CSS 스킨 | Claude가 링크와 body 클래스로 활성화 |
| `index.html` | 시맨틱 HTML과 로컬 미리보기 입구 | 게임 페이지로 교체하지 않음 |
| `preview.js` | 부품 HTML 생성 예시와 데모 이벤트 | 샘플 값/데모 이벤트는 연결하지 않음 |
| `components.json` | 클래스·속성·상태·기존 연결 지점 계약 | 구현 체크 목록 |

의존성은 기존 로컬 PNG와 `css/sd-fonts.css`뿐이다. CDN·npm·빌드·ES 모듈·fetch·캔버스 가공이 없다. `.twj-kit` 루트 안에서 디자인 토큰이 공급되며 부품 클래스는 `twj-` 접두사로 기존 이름과 구별한다.

## Claude에게 그대로 전달할 작업 지시

> `docs/ui-kit/index.html`과 `README.md`, `components.json`을 먼저 읽고 UI 키트를 기존 게임에 적용해 줘. HTML/CSS로 구성된 실제 부품을 사용하고 전체 화면 목업 PNG를 UI 배경으로 붙이지 마. `preview.js`의 HTML 구조는 참고하되 샘플 카드 효과·체력·가격·확인 팝업·편성 제한 로직을 게임에 복사하지 마. 게임의 기존 데이터·렌더러·이벤트·대체 리소스 경로를 사용해. 기존 클래스와 필드를 유지하면서 필요한 `twj-` 클래스나 래퍼를 추가하고 현재 `css/sd-theme.css`와 충돌하는 표현만 정리해. 저장·전투·덱·강화·해금·단축키 동작을 유지해. 아래 연결 표 순서대로 작업하고 마지막에 file://·긴 효과·적 4마리·상태 다수·키보드·1024/1280/1440 해상도를 검사해 줘. 390px 시안은 디자인 참조이며 현재 게임의 최소 폭을 바꾸는 작업은 따로 확인해.

## 기존 코드에 바로 입히는 선택형 스킨

`game-skin.css`는 현재 `.btn`, `.card`, `.cname`, `.ctext`, `.hero-pick`, `.lb-*` 클래스에 맞춘 별도 적용 파일이다. Claude가 기존 HTML의 `css/sd-theme.css` 링크 **뒤에** 아래 링크를 추가하고 body에 클래스를 붙이면 활성화된다.

```html
<link rel="stylesheet" href="docs/ui-kit/game-skin.css">
<!-- 기존 body의 다른 클래스가 있으면 보존 -->
<body class="twj-game-skin">
```

기존 body 클래스가 동적으로 변경된다면 초기화 시 `document.body.classList.add('twj-game-skin')`를 사용한다. 이 키트는 실제 `index.html`을 고치지 않았다. body 클래스 제거로 스킨을 되돌릴 수 있다. 현재 요소의 크기·전투 배치·드래그 변환·입력 이벤트·데이터는 교체하지 않는다. 전용 PNG 카드 프레임이 있는 `.has-frame` 카드는 CSS 틀로 바꾸지 않는다. 새 화면 조합/부품은 별도 `ui-kit.css`와 대응표로 단계적으로 연결한다. **선택형 스킨 하나가 13개 화면의 구조까지 모두 재배치하는 것은 아니다.**

## 실제 게임 연결 지점

| 게임 위치 | 기존 요소 | 키트 부품 / 가져올 내용 |
|---|---|---|
| `index.html`, `css/sd-theme.css` | 화면 루트·공통 토큰 | `.twj-kit` 또는 동일 토큰, 로컬 CSS 링크와 경로 |
| `js/ui-common.js`의 `UI.cardEl` | `.card`/`.cin` | `.twj-card`, `data-frame`, `data-rarity` |
| 같은 함수 | `.cf`/`.cart`/`.ccost` | `.twj-card__frame`/`__art`/`__cost`; 실제 삽화 우선·기존 대체 유지 |
| 같은 함수 | `.cname`/`.csub`/`.ctext` | 제목 가로쓰기·소유자/등급·최소 14px 효과; `.ccond`·`.cchain` 등 기존 정보도 유지 |
| 기존 카드 툴팁·확대 | `data-tip`/`UI.cardTip` | 키트 상세 창처럼 전체 문장 제공; 별도 샘플 상세 버튼은 게임 상황에 맞춰 기존 카드 조작과 통합 |
| `js/ui-lobby.js` | `.lb-*`/`.tile` | 좌측 동료+대사, 우측 메뉴 그리드, 독립 원정 일지 |
| `js/ui-battle.js` | 상단·유닛·HP·상태·손패·턴 종료 | `.twj-topbar`/meter/status/intent/hand/button; 카드 클릭·드래그·조준선 유지 |
| `js/ui-meta.js` 편성 | `.hero-pick`/`.squad-*` | `.twj-hero`의 선택 표시와 요약; 기존 `UI.spriteEl`/전신 로더 재사용 |
| 같은 파일의 보상/상점/휴식/강화/도감 | 기존 카드와 목록·선택/확인 | panel/hand/grid/table/field/button 조합 |
| 설정 렌더러 | 기존 슬라이더/속도/효과 옵션 | `.twj-setting`/switch/tab; 실제 저장된 설정과 연결 |
| 월드맵·던전 지도 렌더러 | 지점/경로/선택/상세 | `.twj-node` 상태, 클릭 영역, `.twj-panel`; 좌표와 해금은 기존 데이터 |

이 표는 필드 대응이며 클래스 이름만 붙인다고 모든 기존 스타일이 자동 호환되는 것은 아니다. 기존 카드의 `.cin` 위치와 `.cf` 배경, 버튼 의사 요소, 고정 높이·최소 폭·오버플로를 함께 확인한다. 키트 CSS를 전역으로 덮는 방식으로 일괄 적용하지 않는다.

## 부품 사용 규칙

- **버튼**: 네이티브 `button`, `type="button"`, 비활성은 `disabled`. 붉은 주요 버튼은 한 화면의 주요 동작에 제한한다. PNG 버튼은 전체 이미지를 `contain`으로 표시하며 텍스트는 DOM이다. 긴 문구에는 CSS 버튼을 사용한다. 클릭 영역 44px 이상.
- **패널**: 내용이 늘어나는 일반 패널은 CSS 테두리. 장식 패널은 4:3 비율을 유지하고 기존 `panel_border.png` 전체를 표시한다. 상점/대장간의 가변 길이 패널을 PNG 비율에 맞춰 억지로 줄이지 않는다.
- **카드**: 이번 키트의 틀은 **CSS 부품**이며 새 `cards/frames/*.png`가 아니다. 무공·마법/융합·합동기를 `data-frame`으로, 5등급을 `data-rarity`와 문자로 구분한다. 실제 카드 이름/종류/강화/조건/연계/소멸 등 모든 정보를 기존 데이터로 추가한다.
- **카드 그림**: 원본을 읽거나 가공하지 않고 `img`로 직접 표시한다. `contain`으로 전체 그림을 보존한다. 비용·소유자·효과는 이미지에 굽지 않는다. 긴 효과는 효과 영역 스크롤과 기존 전체 툴팁/확대로 모두 확인한다.
- **체력/방어**: 수치와 막대를 함께 표시한다. `--twj-value`에는 게임이 계산한 0~100%를 넣는다. 예시의 분모 50이나 피해 수치를 새 게임 규칙으로 쓰지 않는다.
- **예고**: 아이콘+피해량+연타+대상. 광역/무작위/특수는 기존 종류와 대상 표시를 보존한다. 샘플 예고에 생략된 상태/자원 정보를 제거하지 않는다.
- **편성**: 버튼의 `aria-pressed`, 선택 라벨, 정확한 현재 인원. 해금·선택 제한·직업/레벨/덱 구성은 기존 로직으로 연결한다. 미리보기는 고정 샘플 3명이다.
- **지도**: 현재·완료·가능·잠김을 `data-state`와 문구로 함께 구분. 월드맵 지형·13단계 좌표·던전 분기 수를 키트 샘플의 4노드로 바꾸지 않는다.
- **설정**: 실제 `input`, `label`, 체크 상태. 미리보기는 저장하지 않는다. 저장 초기화는 게임의 기존 확인·백업 흐름을 유지한다.
- **모달**: 제목 연결, Esc 닫기, 포커스 복귀. 툴팁의 색/재질만 가져오고 게임의 기존 hover/키보드·터치 상세 동작을 유지한다.

## 화면별 조합

| 화면 | 부품 조합 |
|---|---|
| 타이틀 | 기존 title 배경 + 큰 제목 + 주요/보조 버튼 + 저장 패널 |
| 로비 | lobby 배경 + 전신 + 한지 대사 + 메뉴 그리드 + 수집/일지 |
| 전투 | 테마 배경 + 유닛 렌더러 + 체력/방어/상태/예고 + 에너지 + 손패 + 기존 조작 |
| 편성 | 3×2 동료 버튼 + 선택 요약 + 준비/공용 덱 + 출발 |
| 월드맵 | 기존 world_map 배경 + 데이터 좌표 노드 + 지역 상세 |
| 던전 지도 | 데이터 기반 분기 + 방 노드 + 자원 + 입장 상세 |
| 보상 | 카드 비교 + 보상 목록 + 선택/넘기기 |
| 상점 | 상품/가격 그리드 + 구매 상세 + 제거 서비스 |
| 휴식 | 선택 패널 + 정확한 회복/강화 결과 |
| 대장간 | 목록 + 강화 전후 카드 + 요구 조건/비용 |
| 도감 | 분류 탭 + 검색/필터 + 목록 + 상세 |
| 기록 | 필터 + 가로 스크롤 표 + 원정 상세 |
| 설정 | 설정 행 + 슬라이더/탭/스위치 + 저장 관리 |

실제 조합 예시는 키트의 로비·전투·편성·시스템 페이지에서 확인한다. 기존 전체 화면 목업은 장식·분위기를 비교하는 자료로 계속 사용한다.

## 경로와 오프라인

이 파일이 `docs/ui-kit/`에 있어 CSS의 상대 경로는 `../../assets/`다. `css/`로 옮기면 `../assets/`로 맞춘다. CSS 파일의 URL은 HTML이 아니라 **CSS 파일 위치**를 기준으로 해석한다. 문자열 상대 경로만 바꾸고 이미지 파일을 자르거나 다시 칠하지 않는다. 기존 로컬 `SD Sans` 글꼴과 라이선스는 그대로 사용한다.

## 새 PNG 생성 상태

이번 작업에서 카드 틀·한지 패널·제목 배너·에너지 보석·상점/대장간/휴식/도감 전용 배경을 추가 생성하려 했지만 이미지 도구가 `usage_limit_reached`로 거절했다. **새 PNG는 전달하지 않았으며 키트에 없는 파일을 참조하지 않는다.** 기존 PNG와 실제 CSS 부품으로 모든 키트 조합을 실행할 수 있다. 전용 배경은 현재 로비/문파/숲 배경을 공용으로 쓰며 목업과 동일한 신규 실내 삽화는 후속 그림 작업이다. CSS 카드 틀을 PNG 파일로 등록하지 않는다.
