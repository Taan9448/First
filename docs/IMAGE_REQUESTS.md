# 그림 요청서 (ChatGPT용)

`tools/gen-image-requests.js`가 게임 데이터에서 만든 문서다(손으로 고치지 않는다). 기술 조건은 `docs/ASSET_SPEC.md`, 작업 방식은 `docs/CHATGPT_BRIEF.md`.
**화풍은 확정됐다(2026-10-04)**: 사용자가 승인한 동료 6명 목업(`assets/characters/{id}_poses.png`)이 모든 그림의 기준이다(선 · 채색 · 비례 · 빛). 남은 시범(묶음 0)도 이 화풍으로 만든다. 표의 "있음"은 이미 올라온 그림이다.

**파일 형식**: 이미 올라온 4자세 아틀라스(`{id}_poses.png`)는 그대로 쓴다. **새로 만드는 그림은 동작마다 한 장**(`{id}_{동작}.png`, 같은 캔버스 · 같은 발 위치)으로 올린다 — 동작별 그림이 있으면 게임이 아틀라스보다 먼저 쓴다.

공통: 그림 안에 글자 · 서명 · 워터마크 없음 · 파일 이름은 표 그대로 · 투명이 필요한 것은 PNG 알파 · 같은 묶음은 같은 화풍(선 굵기 · 왼쪽 위 빛 · 채도)

## 묶음 1 — 동료 6명 (전투 동작 5 + 전신 일러스트 + 컷인 얼굴)

승인된 6명 목업의 대기·공격·스킬·피격은 assets/characters/{id}_poses.png에 적용되어 있다. 좌표는 data/character-art.js. 아래 있음 표시는 이 아틀라스도 포함한다. 쓰러짐 전용 그림과 별도 전신·얼굴은 아직 없고, 현재 전신과 얼굴은 대기 자세를 표시·확대한다. 승인된 외형은 assets/README.md를 따른다.

동작: `idle`(대기, 필수) · `attack`(공격, 필수) · `skill`(기술·마법 시전) · `hit`(맞아서 움찔) · `down`(쓰러짐). 동료는 **오른쪽**을 본다. 여섯 명의 키 차이는 작게(같은 캔버스에서 머리 높이가 비슷하게).
