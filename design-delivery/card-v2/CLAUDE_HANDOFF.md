# 카드 v2 — 개별 이미지 전달

사용자 요청: 카드 등급은 하단에만 표시한다. 우측 상단은 기존 카드 유형(공격/방어/보조/회복/지속/방해) 자리로 유지한다. 기술별 원화와 전투 이펙트는 반드시 각각 독립된 파일로 사용한다.

## 파일 구조

- `art/{카드ID}.png`: 텍스트·프레임 없는 단독 기술 일러스트. 불투명 6:5. 사람/캐릭터가 없는 기술 중심 그림.
- `effects/{카드ID}.png`: 캐릭터와 배경이 없는 단독 스킬 이펙트. 3:2 투명 PNG. 여러 동작이 들어간 시트가 아닌 단일 정지 레이어.
- `frames/ink_base.png`: 무공 계열 공통 틀. `frames/split_base.png`: 마법 계열 공통 틀. 원본 비율 5:7, 투명 창.
- `rarity/{common|uncommon|rare|epic|legendary}.png`: 하단에 붙이는 1~5단계 표시. 다섯 소켓 중 해당 단계 수만큼 빛난다. 등급 이름이나 숫자를 상단에 추가하지 않는다.
- `previews/{카드ID}.html`: 한 카드만 보이는 조립 예시. `index.html`: 한 번에 카드 1개와 그 카드의 독립 이펙트를 확인하는 브라우저. file://에서 실행 가능.
- `manifest.json`, `mapping.csv`: 실제 카드 데이터에 기반한 연결표. `generated`가 false인 항목은 아직 PNG가 없는 제작 대상이다. 빈 항목을 이미 완성된 파일로 취급하지 않는다.
- `metadata/*.json`: 생성 원본 위치, 실제 픽셀 크기, 알파 검사 결과. 생성 원본은 덮어쓰거나 삭제하지 않았다.
- `status.json`: 현재 완료 수와 누락 ID. `cards.json`은 전체 296장(일반/저주 281 + 합동 15)의 데이터 스냅샷이다.

## 카드 조립

게임의 `UI.cardEl`, `G.Assets.cardArt`, `G.Assets.cardFrame`을 확인하고 리소스를 연결한다. 기존 렌더러와 리소스 없는 카드의 폴백을 유지한다. 단순 원화 경로와 프레임 경로를 연결하는 것만으로 새 레이아웃이 완성되지는 않으므로, `preview.css`와 단독 미리보기의 위치를 기준으로 조립한다.

1. 원화 → 설명 배경 → 공통 프레임 → HTML 제목/코스트/유형/설명 → 하단 등급 띠 순서로 배치한다.
2. 제목/수치/강화 표시/조건 충족은 게임에서 계산한다. 이미지에 구워 넣지 않는다. 미리보기 설명은 기본 데이터의 표시 예시이며 실시간 전투 수치의 기준이 아니다.
3. 상단 좌측 코스트, 상단 제목, 우측 상단 유형을 유지한다. 코스트 숫자를 등급으로 사용하지 않는다. 강화 단계와 희귀도도 구분한다.
4. 기존 `cstars` 오른쪽 세로 별과 `cknots`를 새 하단 띠와 동시에 표시하지 않는다. 선택된 등급 표시는 하단 한 곳에만 둔다.
5. 같은 계열의 모든 희귀도에 동일 프레임을 사용한다. 등급 변화는 하단 띠에만 둔다. 원화의 기술 규모는 카드 설명과 희귀도에 따라 달라진다.
6. PNG는 `<img>` 또는 CSS `background-image`로 그대로 표시한다. file://에서 PNG를 캔버스로 다시 저장하거나 픽셀을 읽지 않는다.

프레임 원본은 1060×1484. 원화는 생성 원본 해상도로 제공한다(6:5). 효과는 생성 원본 해상도 1536×1024가 일반적이며, 확정 크기는 개별 metadata를 확인한다. 권장 표시 크기는 프레임 500×700, 원화 600×500, 효과 600×400이다. 배율로 표시하고 원본 파일을 임의로 축소 덮어쓰지 않는다.

등급 띠에는 투명 여백이 있으므로 `preview.css`의 하단 래퍼에서 넘치는 투명 여백을 감춰 표시한다. 등급 띠는 5개 소켓/1~5개 활성 상태가 기준이다. 각 PNG의 실제 알파 경계는 검사 결과에 기록한다.

## 스킬 이펙트 연결

`manifest.cards[].effect`의 `path`, `target`, `visualTarget`, `motif`, `motion`, `cues`, `durationMs`, `anchor`, `source`, `impact`를 사용한다. 좌표는 PNG 내 0~1 정규화 좌표이며 기본 배치 가이드다(`anchorIsApproximate: true`). 최종 전투 연결 때 각 이미지의 실제 화살 끝/타격 중심을 대상 위치에 맞춰 조정한다. 공격은 기본적으로 왼쪽 출발점 [0.20,0.55]에서 오른쪽 타격점 [0.75,0.55]으로 흐른다. 방어·회복·강화는 [0.5,0.5] 중심으로 표시한다.

- 이 파일은 단일 정지 이펙트 레이어다. CSS transform/opacity로 생성 → 타격 → 잔광을 만든다. 실제 프레임 애니메이션이나 스프라이트 시트로 오인하지 않는다.
- 기본 재생 시간: 일반 450ms / 고급 600ms / 희귀 800ms / 영웅 1050ms / 전설 1400ms. 실제 재생 시간은 `G.speed`로 나누고 게임의 연출 대기 구조에 연결한다.
- 상태/방어/회복은 실제 효과 대상에 붙인다. 전체 적은 실제 적 목록에 적용한다. 단일 적 카드를 전체 타격으로 보이게 하지 않는다.
- 다단 공격은 실제 타격 수만큼 표시한다. 자원 조건·방어 조건·인장 마무리는 조건이 해결된 후 표시한다. 시각 연출을 위해 피해·상태·RNG를 추가하지 않는다.
- 저주 카드의 연출은 기존 처리 시점을 따른다. 모래/독기/혈흔은 사용 불가 카드의 잔재이며, 속박은 1코스트로 사용한 뒤 소멸하는 매듭 해제 연출이다. 속박에도 공격 효과를 추가하지 않는다.
- 먹 획/낙관, 단일 화살/화살비, 서리/증기 등의 차이는 카드별 scene/rules/cues에 따른다.
- `prefers-reduced-motion`에서는 이동/확대를 줄이고 짧은 페이드만 사용한다.

## 검수와 이관

원화와 이펙트 모두의 `generated`가 true인지 확인한다. 미완성 파일에는 기존 코드 그림을 사용한다. 게임용으로 이관할 경우 원화는 `assets/cards/art/{id}.png`, 이펙트는 새 버전 폴더 `assets/effects/card-v2/{id}.png`, 공통 프레임/등급 띠도 새 버전 경로를 권장한다. 기존 파일은 사용자 지시 없이 덮어쓰지 않는다. 기존 프레임 API는 희귀도별 단일 프레임을 전제로 하므로 새 공통 틀 + 하단 띠 조립에 맞게 연결부를 조정한다.

게임 연결은 Claude 담당이며 이 전달 폴더는 디자인 리소스와 배치 예시다. 게임 로직/규칙/카드 코스트는 이 작업에서 바꾸지 않는다. 연결 후 `node tools/sync-assets.js`와 실제 전투/덱/보상 화면의 이미지 경로, 카드 설명, 파일 실행, 콘솔 오류를 확인한다.
