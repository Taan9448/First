# 카드 먼저 — 원화 / 개별 카드 미리보기 전용

사용자 요청에 따라 **카드 원화를 먼저 완성하고, 이펙트 작업은 보류**합니다. 이 폴더에는 전투 이펙트 PNG나 이펙트 미리보기가 없습니다.

현재 완성 원화 187/296장, 독립 카드 미리보기 PNG 187장입니다. 원화 109장은 실제 이미지 도구 사용 한도 때문에 아직 생성하지 못했습니다. 초기화 안내: 한국시간 2026년 10월 5일 오전 8시 58분경(UTC 10월 4일 23:58경). 전체 카드 완성으로 취급하지 마세요.

- `index.html`: 완성된 카드만 한 장씩 확인합니다. ‘원화만 보기’로 프레임 없는 그림을 확인할 수 있습니다.
- `art/{ID}.png`: 독립 원화 187장. 그림 한 파일에 카드 여러 장을 넣지 않았습니다.
- `previews/{ID}.png`: 제목·코스트·설명·하단 등급을 조립한 한 장짜리 카드 미리보기 187장.
- `frames/`, `rarity/`: 공통 프레임 2종 / 하단 1~5단계 띠 5종. 등급은 하단에만 두고 우측 상단의 게임 유형 이름을 유지합니다.
- `cards.json`, `mapping.csv`: 296장 전체의 카드 연결표. `generated: false`는 원화가 없는 상태입니다.
- `resume-art-only-jobs.json`: 미생성 **원화 109장만** 담은 재개 목록. 이펙트 요청은 포함하지 않았습니다.
- `status.json`: 카드 우선 진행 상태와 미생성 ID.

이 자료는 Claude가 게임에 적용할 카드 디자인 전달 파일입니다. 원본과 기존 게임 리소스를 덮어쓰지 않습니다. 게임 본체에는 아직 연결하지 않았습니다. 원화/등급 레이어의 적용 방식은 기존 `../card-v2/CLAUDE_HANDOFF.md`에서 카드 조립 부분만 참고하세요.

추가 원화를 만들 때 `../card-v2/art/`에 카드 ID로 저장하고 해당 원화의 단독 카드 PNG 미리보기를 만든 다음 `node design-delivery/cards-only/build-cards-only.cjs`로 이 카드 전용 패키지를 갱신합니다. **카드 296장이 먼저 완성될 때까지 새 전투 이펙트 생성은 진행하지 않습니다.**
