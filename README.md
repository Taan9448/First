# 다섯 영웅의 원정 (가제)

브라우저용 턴제 덱빌딩 전략 카드 게임. 순수 HTML + CSS + JS로 만들고, `index.html`을 더블클릭하면 바로 실행된다.

- 기준 문서: [GAME_DESIGN.md](GAME_DESIGN.md)
- 인수인계서(이전 세션 결정 사항): [docs/HANDOFF.md](docs/HANDOFF.md)

## 진행 상황

|---|---|---|
| 1 | 기획서 작성 | 완료 |

## 실행
`index.html`을 더블클릭해서 브라우저로 연다. 진행은 브라우저에 자동 저장된다.
화면 글꼴은 인터넷이 연결되어 있으면 한글 도트 글꼴(갈무리)을 불러오고, 오프라인이면 시스템 글꼴로 보인다.
오른쪽 위 메뉴에서 도감·덱 편집·설정(볼륨, 이펙트 강도, 전투 속도)을 연다.
주소 뒤에 `?debug=1`을 붙이면 디버그 모드(별도 저장, 전체 해금, 적 즉사 버튼, 설정 창의 디버그 버튼)로 열린다.

## 테스트
```
node tools/test-battle.js        # 전투 엔진 자동 테스트 (데이터 검사, 규칙, 무작위 전투 3000회)
node tools/test-campaign.js      # 진행 자동 테스트 (새 게임 → 엔딩, 보상·상점·휴식·합류·저장)
node tools/sim.js 100            # 밸런스 시뮬레이터 (AI가 캠페인 100회, 스테이지별 시도 횟수)
```

## 여러 PC에서 작업하기
작업을 시작하기 전에 `git pull`로 최신 내용을 받고, 끝나면 커밋하고 푸시한다.
