# 다섯 영웅의 원정 (가제)

브라우저용 턴제 덱빌딩 전략 카드 게임. 순수 HTML + CSS + JS로 만들고, `index.html`을 더블클릭하면 바로 실행된다.

- 기준 문서: [GAME_DESIGN.md](GAME_DESIGN.md)
- 인수인계서(이전 세션 결정 사항): [docs/HANDOFF.md](docs/HANDOFF.md)

## 진행 상황
| 단계 | 내용 | 상태 |
|---|---|---|
| 1 | 기획서 작성 | 완료 |
| 2 | 전투 엔진 + 데이터 형식 + 도트 그래픽 | 검토 대기 |
| 3 | 화면 흐름·저장 + 카드 192장·몬스터 36종 | 예정 |
| 4 | 도감·덱 편집·설정·튜토리얼 + 이펙트 | 예정 |
| 5 | 밸런스 시뮬레이션·버그 수정 | 예정 |

## 실행
`index.html`을 더블클릭해서 브라우저로 연다. 주소 뒤에 `?debug=1`을 붙이면 전투 화면에 '적 즉사' 버튼이 생긴다.

## 테스트
```
node tools/test-battle.js        # 전투 엔진 자동 테스트 (데이터 검사, 규칙, 무작위 전투 3000회)
```

## 여러 PC에서 작업하기
작업을 시작하기 전에 `git pull`로 최신 내용을 받고, 끝나면 커밋하고 푸시한다.
