# 천외검결 — 두 세계의 검

브라우저용 턴제 덱빌딩 전략 카드 게임. 무림 + 마법 퓨전 판타지: 문파에 배신당한 검객 서하린이 기연으로 판타지 세계에 건너가 무공과 마법을 익히고 돌아와 배신자를 처단한다. 순수 HTML + CSS + JS로 만들고, `index.html`을 더블클릭하면 바로 실행된다.

- 기준 문서: [GAME_DESIGN.md](GAME_DESIGN.md)
- 인수인계서(이전 세션 결정 사항): [docs/HANDOFF.md](docs/HANDOFF.md)

## 실행
`index.html`을 더블클릭해서 브라우저로 연다. 진행은 브라우저에 자동 저장된다(저장 칸 3개, 칸마다 게임 모드 노말·하드·하드코어).
화면 글꼴(갈무리 등)은 게임에 쓰는 글자만 담아 `css/fonts.css`에 내장되어 있어 인터넷이 없어도 같은 글꼴로 보인다(새 글자를 넣으면 `python3 tools/embed-fonts.py`).
시작하면 로비가 열린다. 로비에서 원정·지도·동료·편성·덱·도감·기록으로 가고, 다른 화면에서는 오른쪽 위 메뉴에서 도감·덱 편집·설정(볼륨, 이펙트 강도, 전투 속도)을 연다.
주소 뒤에 `?debug=1`을 붙이면 디버그 모드(별도 저장, 전체 해금, 적 즉사 버튼, 설정 창의 디버그 버튼)로 열린다.

## 테스트
```
node tools/test-battle.js        # 전투 엔진 자동 테스트 (데이터 검사, 규칙, 무작위 전투 6000회)
node tools/test-campaign.js      # 진행 자동 테스트 (새 게임 → 엔딩, 던전 지도·보물 방·보상·상점·휴식·강화·이벤트·합류·저장)
node tools/sim.js 100 1 10       # 밸런스 시뮬레이터 (캠페인 100회, 시드 1, 기본 원정 뒤 승천 1~10까지 이어서)
node tools/sim.js 12 1 0 hard    # 하드 모드로 시뮬레이션 (넷째 인자: normal | hard)
node tools/doc-upgrades.js       # 카드 강화 규칙을 바꾼 뒤 기획서 8장 '강화' 열을 다시 쓴다
tools/sprites.html               # 브라우저로 열면 모든 캐릭터·몬스터 도트 그림을 미리 본다
```
