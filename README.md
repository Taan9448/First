## 실행
`index.html`을 더블클릭해서 브라우저로 연다. 진행은 브라우저에 자동 저장된다.
화면 글꼴은 인터넷이 연결되어 있으면 한글 도트 글꼴(갈무리)을 불러오고, 오프라인이면 시스템 글꼴로 보인다.
시작하면 로비가 열린다. 로비에서 원정·지도·동료·편성·덱·도감·기록으로 가고, 다른 화면에서는 오른쪽 위 메뉴에서 도감·덱 편집·설정(볼륨, 이펙트 강도, 전투 속도)을 연다.
주소 뒤에 `?debug=1`을 붙이면 디버그 모드(별도 저장, 전체 해금, 적 즉사 버튼, 설정 창의 디버그 버튼)로 열린다.

## 테스트
```
node tools/test-battle.js        # 전투 엔진 자동 테스트 (데이터 검사, 규칙, 무작위 전투 3000회)
node tools/test-campaign.js      # 진행 자동 테스트 (새 게임 → 엔딩, 갈림길·보상·상점·휴식·강화·이벤트·합류·저장)
node tools/sim.js 100 1 10       # 밸런스 시뮬레이터 (캠페인 100회, 시드 1, 기본 원정 뒤 승천 1~10까지 이어서)
node tools/doc-upgrades.js       # 카드 강화 규칙을 바꾼 뒤 기획서 8장 '강화' 열을 다시 쓴다
tools/sprites.html               # 브라우저로 열면 모든 캐릭터·몬스터 도트 그림을 미리 본다
```

## 여러 PC에서 작업하기
작업을 시작하기 전에 `git pull`로 최신 내용을 받고, 끝나면 커밋하고 푸시한다.
